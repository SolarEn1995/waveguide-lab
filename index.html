光是怎麼被困在鏡片裡的？

智慧眼鏡的顯示核心在一片「光波導鏡片」：微型投影機的光被關在極薄的介質裡，靠全反射一路傳遞到眼前，而你依然能清楚看見外面的世界。本頁從整副眼鏡的結構拆解，一路放大到玻璃與碳化矽（SiC）的折射率與能帶物理，每個章節都能直接動手操作。

先備知識：看懂這頁的 7 個小觀念

完全沒有光學或材料背景也沒關係。每個觀念只有一句話、一個生活例子和一個小實驗。點標題可以展開或收合。

1折射光換材料時會轉彎

光從一種材料進到另一種材料（例如從空氣進到水裡）時，會轉個彎。

🥤 生活類比　把吸管放進水杯，從側面看，吸管在水面那裡好像「折斷」了，就是光轉彎造成的錯覺。

45°

2折射率光在材料裡「走多慢」

折射率 n 就是光在材料裡慢了幾倍：n 越大，光走得越慢，轉彎也越明顯。

🏃 生活類比　從柏油路跑進沙灘，腳步會變慢。斜斜衝進去時，先踩到沙的那隻腳先慢下來，人就跟著轉向，這就是光轉彎的原因。

示意：光速 ≈ 30 萬 km/s ÷ n，各材料取代表性的折射率（光學玻璃以波導常用的 n ≈ 1.8 表示）。

3全反射斜到一個程度，光就出不去

光從「走得慢」的材料射向「走得快」的材料時，只要角度斜過臨界角，就會全部彈回來，一點都出不去。

🤿 生活類比　潛水時斜斜往上看，水面像一面鏡子。光纖也是用這招，把光關在細細的玻璃絲裡傳得很遠。

30°

—

4繞射光柵與彩虹紋極細的刻紋會把白光拆成七彩

表面如果有一排比頭髮細上百倍的規則刻紋（光柵），白光碰到後會依顏色分往不同方向，於是看到彩虹。

💿 生活類比　CD 光碟背面會出現彩虹，就是因為上面有一圈圈極細的軌道。

5能隙：透明還是吸光光子的能量夠不夠把電子踢上去

材料裡的電子要一口氣拿到夠大的能量（能隙）才跳得上去。光子能量不夠，就直接穿過（透明）；夠的話會被吸收（不透明）。

⚽ 生活類比　像把球踢上一個高台，每顆光子只能踢一腳。力道不夠，球上不去，光就穿過；力道夠，電子被踢上去，光就被吃掉。藍紫光力道最大，紅光最小。

3.26 eV

6摻雜放進一點點別種原子

在材料裡刻意放進少量別種原子，就能改變它的顏色、導電性或折射率。

🧂 生活類比　像煮湯加一小撮鹽：量很少，味道卻明顯改變。

示意：點灰色的碳原子會換成綠色的氮原子（再點一次換回來）。顏色與數值是教學示意，不是實際配方。

7畫面藏在角度裡一個像素＝一個方向

光機的光經過透鏡後，每個像素都變成一束朝特定方向的平行光。所以鏡片裡傳的不是「一張圖」，而是一組「方向」：方向的範圍越寬，畫面越大。

🌟 生活類比　星星的光到地球時是平行光。你往旁邊走一步，星星還在天空同一個位置：眼睛是用「光從哪個方向來」判斷位置，而不是光打在哪裡。

這就是 第 3 章「折射率決定能裝多少畫面」→ 的關鍵：能被鏡片關住的方向越多，畫面就越大。

示意：點按鈕或畫布可以換像素。真實光機有幾十萬個像素，每個都對應一個方向；角度已放大，方便看清楚。

    ？光柵是幹嘛的？彩虹紋從哪來？三格圖解＋小實驗（示意）
    ① 光柵是什麼

    刻在波導表面的奈米細紋。就像 CD 光碟表面的細紋，會讓光出現彩虹。

    ② 光柵的兩個工作

    入口把光機的光「掰彎」，讓它被困在板子裡；出口把光「放出去」給眼睛。

    ③ 為什麼會有彩虹紋

    外界白光打到出口光柵，也會被依顏色分開，眼睛就看到彩色光斑或光帶。

    對照　反射式（Ray-Ban）沒有光柵，所以沒有彩虹紋，但有其他難題（鬼影、亮度均勻）；繞射式有光柵，所以要想辦法壓低。

    澄清　這和一般近視眼鏡無關，彩虹紋來自波導上的光柵。

    區分　彩虹紋專指外界光被出口光柵拆成的彩色；光機自己的光因顏色路徑不同造成的是色偏，兩者不同。（示意）

    小歷史　早期用多片玻璃波導疊出全彩的設計，彩虹紋明顯，Meta 的科學家形容過「到處都是彩虹」；改用碳化矽後大幅減少。

    圖解與小實驗為教學示意，不代表實際光柵尺寸與角度。

    ？高折射率為什麼能減少彩虹紋？研究論文，非 Meta 原話（示意）
    1. 光柵週期可以更細研究論文中，折射率 1.9 的參考設計約需 370 nm 週期，碳化矽設計用 262 nm（單層、全彩、30° 視野）。
    2. 外界白光被撥到看不到的方向週期更細加上折射率更高，外界光的繞射角更大，大多落在眼睛接收範圍之外。
    3. 單層取代多層一片就能全彩，不用每種顏色疊一片（Meta 也說玻璃要疊兩三片，碳化矽一片）。

    💡 類比　光柵像把光「撥」一個角度，週期越細撥越大，外界白光就被撥到你看不到的地方。

    03

    全反射：折射率決定能裝多少畫面

    光從高折射率材料射向空氣時，只要入射角超過「臨界角」就會全部反射回鏡片內。折射率越高，臨界角越小，可用來傳遞畫面的導光角度區間越寬，視野（FOV）也越大。

    一句話重點

    光從高折射率材料射向空氣時，角度超過臨界角就會全部反射；折射率越高，臨界角越小，能被關在鏡片裡的角度範圍越寬，視野（FOV）也越大。

    生活類比

    像一扇門：折射率越高，門開得越寬，能同時通過、送到眼前的「畫面角度」越多，你看到的畫面就越大。（示意）

    公式：θc = arcsin(1 / n)。綠色扇形代表「可用來導光的角度範圍」（從 θc 到約 75°）。

    為什麼折射率越高，視野越大？四步推理

    1. ① 折射率高光在材料裡走得更慢，碰到表面時轉彎更明顯。
    2. ② 臨界角小θc = arcsin(1/n)：n 越大，觸發全反射的門檻角度越小。
    3. ③ 可用導光角度範圍大從臨界角到約 75° 的光都能被關在鏡片裡；臨界角越小，這段範圍越寬。
    4. ④ 視野大能被關住、送到眼前的畫面角度越多，你看到的畫面就越大（FOV 越大）。

    視野理論上限（簡化估算）

    估算式：FOV ≈ 2·arcsin[(n·sin75° − 1) / 2]，以繞射式耦合、單一方向、單一顏色推得，用於比較不同材料的趨勢。若紅綠藍三色要共用同一組光柵（單片全彩），條件更嚴格：玻璃 1.8 單一方向約 20°、碳化矽 2.65 約 64.5°，換算成對角線仍可超過 70°。下方刻度標示實際產品：Ray-Ban Display 對角 20°（反射式玻璃波導），Orion 約 70°（碳化矽繞射式波導）。

    摻雜實驗：加了什麼，鏡片就變了什麼

    同樣是「在材料裡加入其他元素」，在玻璃與碳化矽中造成的結果完全不同：玻璃加入重元素氧化物是為了拉高折射率；碳化矽摻入氮元素則會帶進大量自由電子，這些電子會吸收部分可見光，讓晶體偏綠、變暗。

    一句話重點

    同樣是在材料裡加東西：玻璃加入重元素是為了提高折射率；碳化矽摻氮是為了導電，但多出來的自由電子會吸收部分可見光，讓晶體偏綠、變暗，所以鏡片要用高純度的碳化矽。

    生活類比

    像煮湯：加一點鹽讓湯更好喝（玻璃加重元素）；倒進一大匙醬油，湯就黑到看不見碗底（碳化矽摻氮變暗）。

    四種波導材料比較

    核心權衡：折射率越高，能支援的視野越寬，但材料成本與加工難度也越高。標註星號（★）為本報告重點案例。

    一句話重點

    折射率越高，能做出的視野越大，但材料成本與加工難度也越高：Ray-Ban Display 選高折射率玻璃、已量產；Orion 選碳化矽、視野約 70°，目前是原型機。

    生活類比

    像挑相機鏡頭：越廣角、越好的鏡頭通常越貴、越難做，要看用途和預算取捨。

    n ≈ 1.5–1.7

    聚合物（樹脂）

    • 優點：便宜、輕量、耐摔，可射出成型
    • 缺點：折射率低導致視野受限；表面平整度較難控制
    • 現況：多家廠商同步開發玻璃與聚合物版本
    n ≈ 1.5–2.0 ★

    高折射率光學玻璃

    • 優點：透明度高、平整度極佳，已成熟量產
    • 缺點：折射率上限約 2.0；折射率越高通常密度越重
    • 案例：Ray-Ban Display（反射式，應為 SCHOTT 製造）
    n ≈ 2.3

    鈮酸鋰（LiNbO₃）

    • 優點：單晶材料，折射率明顯高於光學玻璃
    • 缺點：Meta 曾評估過，最終因綜合考量改選碳化矽
    • 角色：介於玻璃與碳化矽之間的過渡選項
    n ≈ 2.7 ★

    碳化矽（SiC）

    • 優點：可見光區最高折射率之一；導熱極佳、高硬度、耐化學腐蝕
    • 缺點：長晶與加工昂貴；電動車用晶圓摻氮多，偏綠近黑、不透光
    • 案例：Meta Orion 原型機，達成約 70° 視野並大幅減少彩虹紋

    Ray-Ban 視野小是刻意設計（瞥一眼）；反射式能否做大視野，業界已有 70° 原型，尚未量產。

    Meta 說 Orion 的首要目標是視野，減少彩虹紋是碳化矽的好處之一。

    反射式 70° 原型（Lumus ZOE，公司自稱，用標準光學玻璃）已在 CES 2026 展出，尚未量產；其具體技術細節未公開。

    ？Meta 為什麼選碳化矽（不只是視野）五個理由（示意）
    1. 折射率高約 2.7，比玻璃 1.8 高約 50%，能把更大範圍的畫面角度關在鏡片裡。
    2. 一片取代兩三片玻璃更輕、更薄，也減少多片之間的對位。
    3. 大幅減少彩虹紋繞射式的老問題大幅改善。
    4. 導熱碳化矽導熱好。
    5. 透明且光學特性可均勻光學級的碳化矽透明，光學特性也能做得均勻。

    成本不是選它的理由：起初很貴，現在因電動車市場產能過剩而下降。

    示意／資料來源：Meta 技術文章、Engadget、Tom's Guide
